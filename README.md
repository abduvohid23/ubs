# Kutubxona dasturi

Python yordamida yaratilgan oddiy kutubxona boshqaruv dasturi.

## Imkoniyatlari

- Kitob qo'shish
- Kutubxonadagi kitoblarni ko'rish
- Kitob o'chirish
- Dasturdan chiqish

## Ishga tushirish

Kompyuterda Python o'rnatilgan bo'lishi kerak.

Terminalda:

```bash
python main.py
```
